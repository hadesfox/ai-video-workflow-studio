# 素材库入口 + 角色配音绑定 + 提示词 @配音 功能设计

> 项目：ai-video-workflow-studio
> 技术栈：React 19 + Vite + Tailwind（CDN 配置）+ lucide-react + framer-motion
> 状态式导航：`MainTab` 枚举（App.tsx 全局状态驱动）

---

## 1. 背景与目标

在现有「AI 视频创作工作流」中补齐素材管理与配音绑定能力：

1. 顶部标题栏新增「素材库」入口，进入素材库页；素材按类型（配音、音乐音效、视频、图片）分类管理，支持上传。
2. 资产管理页的角色资产详情弹窗中新增「配音绑定」按钮；弹窗展示素材库已上传的配音、顶部带类型筛选；选中配音后确认即绑定到角色资产。
3. 视频管理的提示词生成时，在 `@资产名字` 之外，同步 `@` 该角色已绑定的配音素材。

成功标准：

- `npm run build` 通过（TypeScript 无报错）。
- 三条路径均可在 UI 上完整走通。
- 配音标签不触发分镜「缺失资产」红色告警。

## 3. 数据模型设计（`types.ts`）

### 3.1 `MainTab` 新增

```ts
export enum MainTab {
  // ...现有值
  MATERIAL_LIB = 'MATERIAL_LIB'
}
```

### 3.2 素材类型与实体

```ts
export enum MaterialType {
  VOICE = 'VOICE',          // 配音
  MUSIC_SFX = 'MUSIC_SFX',  // 音乐音效
  VIDEO = 'VIDEO',          // 视频
  IMAGE = 'IMAGE'           // 图片
}

export interface Material {
  id: string;
  name: string;
  type: MaterialType;
  url: string;        // data URL / 外部 URL（复用 FileReader.readAsDataURL 模式）
  fileName?: string;  // 原始文件名
  duration?: number;  // 秒（音/视频可选）
  size?: number;      // 字节
  createdAt: number;
}
```

### 3.3 `Asset` 新增绑定字段

配音绑定在**角色资产（Asset）级别**，而非单个状态（AssetState）级别，因为声音是角色属性，与形态状态无关。

```ts
export interface Asset {
  // ...现有字段
  boundVoiceId?: string;   // 绑定的配音素材 id
  boundVoiceName?: string; // 绑定的配音素材名（冗余存储，便于提示词直接拼接）
}
```

## 4. 功能设计

### 4.1 素材库页面（新建 `components/MaterialLibrary.tsx`）

Props：

```ts
{
  materials: Material[];
  setMaterials: React.Dispatch<React.SetStateAction<Material[]>>;
  onBack: () => void;
}
```

- 页头：标题「素材库」+「返回」按钮（调用 `onBack`）+「上传素材」按钮。
- 顶部类型筛选 Tab：`ALL / VOICE / MUSIC_SFX / VIDEO / IMAGE`，复用 `AssetManagement` 现有 Tab 激活态样式（`bg-slate-700 text-white`）。
- 素材卡片网格：
  - 类型图标：配音 `Mic`、音乐音效 `Music`、视频 `Video`、图片 `ImageIcon`。
  - 音频/视频卡片提供 `<audio>` / `<video>` 预览或播放按钮。
  - 展示名称、文件名、时长/大小；卡片右上角删除按钮。
- 上传弹窗：类型下拉 + 名称输入 + 文件选择（`<input type="file">` → `FileReader.readAsDataURL`），确认后追加一条 `id = Date.now()` 的素材。
- 空状态：「暂无素材，点击右上角上传」。

### 4.2 App 接线（`App.tsx`）

1. 引入 `MaterialLibrary`、`Material` 类型、`Library` 图标。
2. 新增全局状态：`const [materials, setMaterials] = useState<Material[]>([])`（素材库为全局资源，与项目解耦）。
3. 头部右侧（生成器按钮旁）新增「素材库」按钮，始终可见，不依赖项目选中：

5. 向 `AssetManagement`、`StageVideo` 各传入 `materials` 属性。

### 4.3 角色资产「配音绑定」（`components/AssetManagement.tsx`）

1. `AssetManagementProps` 新增 `materials: Material[]`。
2. 新增弹窗状态：
   - `showVoiceBindModal: boolean`
   - `voiceBindTypeFilter: MaterialType`（默认 `VOICE`）
   - `selectedVoiceId: string | null`
3. 在 State Detail Modal 右栏（`activeAsset.type === 'CHARACTER'` 时）新增「配音绑定」区块：
   - 按钮打开绑定弹窗，并预选 `activeAsset.boundVoiceId`。
   - 展示当前绑定：有则显示 `boundVoiceName`，无则显示「未绑定」。
4. 新增「绑定配音」弹窗（沿用现有 `fixed inset-0 z-[100]` 弹窗样式）：
   - 标题「绑定配音」，右上角关闭。
   - 顶部类型筛选 Tab：`VOICE / MUSIC_SFX / VIDEO / IMAGE`（默认 `VOICE`）。
   - 列表项单选（高亮选中态），**仅 `VOICE` 类型可选中**，其它类型若被筛选显示则置灰/禁用。
   - 空状态：「暂无配音素材，请先前往素材库上传」。
   - 底部「确认绑定」：校验选中素材为 `VOICE` 后执行：

```ts
setAssets(prev => prev.map(a => a.id === activeAsset.id
  ? { ...a, boundVoiceId: m.id, boundVoiceName: m.name }
  : a));
```

   - 关闭弹窗；可选提供「取消绑定」清空两个字段。

### 4.4 提示词同步 @配音（`components/StageVideo.tsx`）

1. `StageVideoProps` 新增 `materials: Material[]`。
2. 配音引用格式约定：`【@配音:名字】`（与资产 `【@名字-状态】` 区分，用 `配音:` 前缀 + `:` 分隔，避免与状态 `-` 冲突）。
3. 修改 `generateShotPrompt`：在 `char` 存在且 `char.boundVoiceName` 有值的分支中，语句末尾追加：

```ts
if (char?.boundVoiceName) prompt += `【@配音:${char.boundVoiceName}】`;
```

4. 修改 `checkShotIssues`：循环内跳过配音标签，避免误判为缺失资产：

```ts
if (tagContent.startsWith('配音:')) continue;
```

5. 修改 `extractAssetsFromPrompt` 与「关联资产」渲染：
   - 识别 `配音:` 标签，push `{ name, url: '', type: 'VOICE' }`。
   - 关联资产渲染处：`type === 'VOICE'` 时用 `Mic` 图标替代 `<img>`。
   - `renderHighlightedPrompt` 现有 `【@...】` 分割已能高亮配音标签，无需改动。

## 6. 边界情况与失败模式

- **素材库为空**：绑定弹窗与素材库页均显示空态提示，不崩溃。
- **角色未绑定配音**：提示词不追加 `@配音` 标签（保持原行为）。
- **非角色资产（场景/道具）**：不显示「配音绑定」按钮。
- **配音素材被删除但角色仍绑定**：`boundVoiceName` 保留旧名；`checkShotIssues` 已跳过配音标签故不报红。本期不做自动解绑（已知限制）。
- **上传大文件**：沿用 data URL，仅提示「演示环境建议小文件」，不做大小限制阻断。
- **命名冲突**：素材名允许重复，绑定以 `boundVoiceId` 为准。

## 7. 测试与验收

1. `npm run build` 通过。
2. 素材库：头部入口进入 → 切换类型 Tab → 上传配音/音乐/视频/图片 → 列表展示、可删除。
3. 绑定：角色资产详情弹窗 → 点「配音绑定」→ 弹窗默认显示配音、顶部可切类型 → 选中配音 → 确认 → 详情区显示已绑定名字；再次打开预选当前绑定。
4. 提示词：视频管理「生成分镜」后，含角色的分镜提示词末尾出现 `【@配音:名字】`；右侧缩略导航不出现红色缺失告警；提示词高亮显示配音标签；「关联资产」区以麦克风图标展示配音。

---

## 8. 关键假设

- 素材库为全局资源（不随项目隔离），故放在 App 全局状态并从头部常驻入口进入。
- 素材类型取「配音 / 音乐音效 / 视频 / 图片」四类（满足「…等」的扩展空间）。
- 配音绑定作用于角色资产（`Asset`）级别而非单个状态级别。
