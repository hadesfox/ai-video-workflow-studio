# AI 视频创作工作流 Studio —— 产品功能说明文档

> 文档视角：产品经理
> 适用对象：需求评审、开发对齐、演示讲解
> 配套演示：本地运行 Demo（账号 admin / 123456），本仓库为可运行原型（生成类操作均为模拟）
> 文档说明：本文档覆盖系统全部模块的功能与交互细节，不含实现方案与数据结构约定。

---

## 1. 产品定位

面向影视 / 短视频团队的一站式 AI 视频创作工作流平台。用户导入剧本后，系统以「多智能体」协作的方式完成资产提取、详情生成、批量出图、主体库沉淀、分镜生成、视频生成、在线剪辑、审片交付、外发协作的全链路生产，并配套模型配置、账号权限、消耗统计等后台能力。

**核心价值**：把「剧本 → 成片」从人工拆解变为 AI 驱动的流水线作业，并通过「主体库 + 素材库 + 外发协作」保障跨剧集、跨团队的一致性。

## 2. 整体架构与导航

### 2.1 导航结构

- **顶部主导航**（选中项目后显示），五个主 Tab：
  1. **资产管理**（子 Tab：剧集管理 / 图片资产 / TTS 配音）
  2. **主体库管理**（子 Tab：seedance / spark）
  3. **视频管理**
  4. **成稿管理**（子 Tab：在线审片 / 成稿交付）
  5. **外发协作**
- **顶部常驻入口**（登录后始终可见，不依赖项目）：
  - 素材库（全局素材资源）
  - 视频创作工具（独立单点生成器）
  - 主题切换（日光 / 黑夜 / 迷彩 / 莫兰迪 / 扁平化 / 复古 六套主题）
  - 用户头像菜单（个人中心 / 后台管理 / 退出登录）
- **项目激活态额外显示**：返回箭头 + 项目名（随时可回到项目库）、余额胶囊。
- **外部协作方视角**：开启「外部视图」后无论当前 Tab 一律渲染外发协作工作台，顶部显示橙色标识，模拟外包方视角。

### 2.2 主流程

```
登录 → 项目库（选择/新建项目）→ 资产管理（剧本拆分 → 提取资产 → 生成详情 → 批量出图 → 风格参考/世界观/配音绑定）
→ 主体库（有图状态入库、AI 识别风格、一致性比对）
→ 视频管理（生成分镜 → 提示词编辑 → 视频生成（多引擎/多模式/多版本）→ 错误处理）
→ 成稿管理（在线剪辑 → 在线审片（时间码批注/版本/状态）→ 导出交付）
→ 外发协作（素材下发 → 外包交付 → 审片通过/打回）
```

## 4. 项目库

### 4.1 项目列表

- 左侧筛选栏：全部 / 制作中 / 测试中 / 已完成 / 已取消 / 已归档（后三项暂无数据来源）。
- 项目卡片网格：名称、制作类型徽章（剧情短片 / 解说短片）、状态、所属项目组；置顶「新建项目」虚线卡片。

### 4.2 新建项目（三步带卡点）

1. 点击「新建项目」→ 先弹「全局设置检查」：未完成 Agent 配置时提醒，可「去检查设置」或「已完成，继续创建」。
2. 填写：所属项目组（可选「无（个人项目）」）→ 上传剧本文件（.txt / .pdf / .docx，上限 50MB）→ 制作类型（解说 / 剧情）。
3. 分支流程：
   - **解说类**：追问「上传的是否是解说剧本」——「是」直接拆分剧本；「否」走 **AI 剧本转换**，生成带画面编号 / 运镜 / 音效 / 解说词的长剧本，可全屏预览（含字数统计）后「确认并拆分」。
   - **剧情类**：直接拆分剧本。
4. 创建后自动选中新项目并进入资产管理。

### 4.3 项目管理

卡片 hover 显示编辑入口：支持改名、改所属项目组、删除（二次确认）。点击卡片 = 进入项目。

## 5. 资产管理（核心模块）

### 5.1 子 Tab

- **剧集管理**：分集文件卡片网格，点击弹剧本预览弹窗查看该集全文。
- **图片资产**：核心功能区（见下）。
- **TTS 配音**：配音生成占位页，「生成所有配音」按钮 + 空态。

### 5.2 图片资产两种视图

- **索引预览**：3:4 竖版封面卡片墙，含类型角标、名称、简介、「第 X 集」出场信息、形象数量统计；点击卡片跳转列表视图并选中该资产。
- **列表预览**：左资产列表（搜索 + 全部/角色/场景/道具 Tab + 出场集数与状态数），右所选资产的状态卡片墙 +「添加新状态」。

### 5.3 AI 提取流水线（按钮依赖链，逐级解锁）

1. **提取资产**：AI 分析剧本产出骨架资产（名称 + 简介 + 多状态），同时生成世界观设定（若开启）。
2. **生成详情**：为每个状态填充英文生图 Prompt 与结构化属性（性别 / 服装 / 时间 / 天气 / 材质等）。
3. **一键生主图**：批量为各资产第一个状态生成主图，首个有图状态设为封面。
4. **一键生状态图**：批量为其余非主状态生成图像。

所有动作经全局 Loading 遮罩呈现「AI 智能体正在处理任务」。

### 5.4 状态（形态）管理

- 每个资产含多个状态（如常规 / 战斗 / 重伤），状态含名称、描述、Prompt、属性、主图、变体缩略图。
- **状态详情弹窗**：左侧大图（可上传更换主图）；右侧可编辑 Prompt（自动增高）、形态简介、**配音绑定区（仅角色显示）**、变体图网格（缩略图可设为主图 / 追加 / 删除，删主图自动顶替）、「立即生成」按钮（消耗 1 点额度，新图进入历史缩略图，上限 8 张）。
- **添加新状态弹窗**：状态名称（必填）+ 描述。
- 支持删除单个状态、删除整个资产（均二次确认）。

### 5.5 新建资产

名称（必填）+ 类型（角色 / 场景 / 道具）+ 简介，创建自动附带「常规状态」；另有「批量创建」「导出资产」入口（预留）。

### 5.6 风格参考

开启开关 → 预设风格（赛博朋克 / 水彩画 / 油画 / 素描 / 极简主义 / 浮世绘）或自定义风格（上传名称 + 参考图）→ 确认风格，约束后续生图视觉统一。

### 5.7 世界观

展示 AI 提取的阵营设定条目（阵营名 + 外观共通元素描述），由「提取资产」阶段按开关生成。

### 5.8 配音绑定（角色专属）

- 角色状态详情弹窗内显示当前绑定配音名或「未绑定」→ 打开**近全屏绑定弹窗**。
- 弹窗**仅列配音类型素材**，带与素材库一致的标签分类、时长筛选、排序；卡片单选，打开时预选当前绑定；支持确认绑定 / 取消绑定。
- 详见《素材库与配音绑定需求文档》。

## 6. 素材库（全局资源）

- 常驻入口，素材按 **配音 / 音乐 / 音效 / 视频 / 图片** 五类分页，**无「全部」**，进入默认空列表，选中类型后加载。
- 每类带**标签分类体系**（如配音：音色 / 场景 / 语言 / 推荐；音乐：风格 / 情绪 / 场景；音效：场景 / 类型等）+ **筛选参数**（时长：10 秒内 / 10-60 秒 / 60 秒以上；排序：最新 / 最早上传；清除筛选）。
- 标签可多选取交集；素材卡片标签可点击直接加入筛选。
- **上传**：类型 → 名称（默认取文件名）→ 标签分类（随类型切换）→ 选文件（按类型限制格式），自动读取预览 / 时长 / 大小；**切换类型时清空已选文件**。
- **删除**：卡片悬停删除，二次确认。
- 详情见《素材库与配音绑定需求文档》。

## 7. 主体库管理

- 入库单元为「资产 × 状态」组合（如「主角 Kael - 战斗状态」），入库时 AI 识别图片风格（真人写实 / 3D 渲染 / 赛博朋克插画 / 电影质感等）。
- **同步规则**：左侧「待同步资产」抽屉列出本地有、主库无的条目；**必须有主图才能入库**，无图显示警示并禁用同步。
- **一键同步**：批量入库所有未同步且有图的条目。
- **出库**：主体详情弹窗支持编辑信息（名称 / 风格 / 描述）与删除；删除仅移除主库副本，**不影响本地资产**。
- **一致性比对**：「比对资产清单」弹窗：四项统计（本地总数 / 主库总数 / 待同步 / 库冗余）+ 左右对照表，三种状态——已同步（绿）/ 待同步（蓝，可同步）/ 库冗余（红，可移除）；支持「待处理优先 / 已同步优先」排序。
- seedance / spark 两个子 Tab 当前内容一致，产品意图为按下游生成模型分库（预留差异化）。

## 8. 视频管理（核心生产环节）

### 8.1 分集与分镜

- 左侧分集列表（可折叠 / 固定，切换分集，+ 新增分集）。
- **生成分镜**：AI 基于剧本 + 资产库生成分镜脚本（一次 10 个镜头，每个含提示词与 3~7 秒时长）；资产库为空时引导先去提取资产；分镜只生成一次，可上/下插入与删除。

### 8.2 提示词与 @标签

- 提示词编辑：铅笔图标进入编辑态，自适应高度；非编辑态高亮 `【@...】` 标签。
- **资产标签** `【@资产名-状态名】`：自动匹配资产库展示参考缩略图；引用不存在资产时镜头标记「有问题」，导航地图标红。
- **配音标签** `【@配音:名字】`：源自角色绑定音色，以麦克风图标展示，**不参与缺失资产校验**。
- 关联资产面板：自动解析展示镜头引用资产（图片缩略图 / 配音麦克风卡片），无引用显示提示。

### 8.3 视频生成

- **双引擎**：Vidu / Seedance 画中画切换器。
  - VIDU：一键生成主体视频（SUBJECT）+ 一键生成图生视频（IMAGE）。
  - SEEDANCE：仅图生视频批量。
- 单镜头三模式：图生视频 / 主体生视频 / 场景图生视频；生成前校验资产有图。
- 状态机：待生成 → 生成中 → 已完成 / 出错（模拟 20% 失败率，记录错误码 / 模型 / 时间戳）。

### 8.4 多版本与错误处理

- 每个镜头维护版本数组，重新生成追加新版本并切到最新；预览支持版本切换；错误状态下可回看历史版本，切换版本即忽略错误。

### 8.5 迷你导航地图

悬浮状态点：白=待生成、黄闪=生成中、绿=已完成、红=错误/缺失；新镜头带「New」红点；点击平滑定位。

### 8.6 视频设置（首次进入强制）

宽高比 16:9 / 9:16 / 1:1 / 21:9；分辨率 720p / 1080p / 2K / 4K；生成时长 5s / 10s。

### 8.7 下载与导出

- 下载弹窗：当前分集 / 整部项目，展示镜头总数 / 已完成数 / 预计文件数，可含历史版本。
- 一键导出剪辑：导出到剪映（生成 .jianyin 草稿）或在线编辑器（组装时间线跳转云剪辑）。

## 9. 成稿管理与在线协作

### 9.1 在线剪辑（Vidu 云剪辑）

- 无片段：落地引导页（连接云端渲染服务器）。
- 有片段：16:9 预览 + 播放控制条、属性面板、双轨时间线（Video 1 / Audio 1、FPS 30、时间码、粉色播放头、片段缩略图、+ 添加片段、背景音乐轨）。

### 9.2 在线审片（类 Frame.io）

- **文件库**：文件 / 分享 / 回收站三 Tab；搜索、网格视图、多选、批量下载、批量设置状态、批量分享；审片项含视频 / 文件夹 / 音频。
- **审阅状态**：待审阅（红）→ 审阅中（黄）→ 意见汇总完毕（蓝）→ 通过（绿），可移除状态。
- **版本管理**：上传版本自动递增 vN；管理弹窗支持拖拽排序、重命名、删除。
- **分享**：审阅分享（配额 2/10）、演示分享 / 交付分享（升级项）；可配版本范围、允许下载 / 批注、密码保护、过期时间，生成链接 + 密码一键复制与扫码。
- **审片播放器**：版本下拉切换（各版本独立批注数据）、播放 / 逐帧进退 / 倍速 / 音量；**时间码批注**（自动锚定当前时间、批注列表按时间码排序、可编辑回复、按时间码 / 版本筛选）；**画面标注**（画笔 / 矩形 / 箭头 / 文字，随批注保存画面快照）。
- **成稿交付**子 Tab：占位页。

### 9.3 导出交付

「制作完成」页三条路径：本地导出（.zip：MP4 + 素材包）、发送至 Premiere（XML 时间线）、在线编辑器（云端微调）。

## 10. 外发协作

### 10.1 任务状态流转（7 态）

```
草稿 draft → 待发布 pending → 已下发 published → 已交付 delivered → 审片中 reviewing → 已通过 approved
                                                        ↘ 已打回 rejected（可重新提交回到 delivered）
```

### 10.2 内部视角（制作方）

- **任务列表**：关键词搜索 + 状态筛选 + 表格（外包方 / 截止时间 / 素材数 / 交付版本数）；待发布可一键下发。
- **新建任务**：任务名称、剪辑需求 Brief、截止时间、指定外包方、多选素材包；创建后进入待发布。
- **任务详情**：状态步骤条、已下发素材包、交付版本记录（含历次审片意见）；已交付 / 审片中状态可执行**通过 / 打回**。

### 10.3 外部视角（外包方）

- **我的任务**：统计卡片（待处理 / 进行中 / 需修改 / 已完成）+ 按状态显示操作入口。
- **下载素材**：按任务勾选或一键打包下载。
- **交付成片**：上传成片（mp4 / mov / mkv，最大 5GB）+ 可选工程文件（prproj / aep / drp）+ 剪辑说明；提交后版本自增，任务转为已交付。
- **反馈处理**：被打回任务查看审片意见并重新提交；已通过任务列表；历史审片记录回溯。

### 10.4 审片意见

评论分打回 / 通过 / 普通意见三类，可携带时间码，与在线审片能力打通。

## 11. 后台管理

侧边栏菜单 6+1 项：

1. **提示词配置管理**：配置项（名称 / 标识 / 类型 / 提供方 GEMINI·OPENAI·ANTHROPIC / 模型 / 思考模式）增删改查与筛选。
2. **提示词类型管理**：动漫生分镜 / vidu+真人 / 通用自动化生成 三类。
3. **提示词模板配置**：预置模板 2D 动画 / 真人实拍 / 3D 渲染；每模板对 15 个环节键（剧本、索引提取道具/场景/人物、世界观、资产详情×3、特殊状态×3、主状态×3、分镜）绑定「模型 + 提示词」；支持另存新模板 / 删除。
4. **账号管理**：用户列表（信息 / 角色 / 项目组 / 权限预览 / 状态 / 最后登录），新增编辑用户（默认密码 123456），权限详情抽屉（有效权限 = 角色权限 ∪ 个人附加权限）。
5. **项目组管理**：项目组 = 组员 + 承接项目，支持添加移除。
6. **角色与权限（RBAC）**：预置管理员 ADMIN / 总导演 / 导演 / 制作四角色；权限分前台配置（创建 / 重命名 / 状态 / 分组 / 删除 / 可见范围）与后台配置（后台访问 / 提示词 / 用户 / 项目组 / 角色权限 / Seedance 统计）两组；角色 × 权限矩阵勾选配置。
7. **消耗统计（Seedance）**：按用户 / 姓名查询 + 日期范围；指标含任务数、成功率、Token、费用、视频时长、耗时，支持排序与导出。

## 12. 独立工具与全局设置

### 12.1 视频创作工具（独立生成器）

脱离项目的单点生成界面：参考图片（≤9，可从主体库挑选或上传）、参考视频（0/3）、参考音频（0/3）、提示词（支持输入 @ 插入资产）、画幅 / 时长（自动）、发送生成；右侧任务预览 + 历史任务列表（任务 ID / 耗时 / 提示词摘要）。当前为预留入口。

### 12.2 全局设置

- **Agent 配置**：4 套模板（2D 动画 / 真人实拍 / 3D 渲染 / 自定义），手动修改自动回退「自定义」；15 个环节各配模型（Flash 标准 / Pro 高智 / Flash-Lite 极速 / 2.5 Flash）+ 提示词预设 + 启用开关（世界观提取可关，联动资产管理）。
- **生成设置**：占位页。

## 15. 各模块与素材库 / 配音绑定的关系

- 素材库为全局资源，供配音绑定（配音类型）与后续音乐 / 音效 / 视频 / 图片创作引用。
- 角色绑定配音后，视频管理生成分镜时自动追加 `【@配音:名字】` 标签，参与高亮与关联资产展示，不触发缺失告警。
- 详细功能与验收标准见《素材库与配音绑定需求文档》。
