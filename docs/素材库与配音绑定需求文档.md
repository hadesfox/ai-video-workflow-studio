# 素材库 + 标签筛选 + 角色配音绑定 + 提示词 @配音 —— 需求文档

> 文档性质：**功能需求基线**，配合本仓库可运行 Demo 逐条演示对齐，不包含实现代码与数据结构约定。
> Demo 入口：本地运行后登录（admin / 123456），头部右侧书本图标进入素材库。

---

## 1. 需求概述

在现有「AI 视频创作工作流」中补齐素材管理与配音绑定能力，共三条主线：

1. **素材库**：顶部标题栏常驻入口；素材按「配音 / 音乐 / 音效 / 图片」四类分页管理；每类带**标签分类体系**与**筛选参数**，支持上传（可打标签）、删除。进入默认空列表，选中类型后才加载对应素材。
2. **角色配音绑定**：资产管理 → 角色资产详情中提供「配音绑定」；绑定弹窗**近全屏、仅展示配音类素材**，带与素材库一致的标签分类与筛选；确认后绑定到角色本身。
3. **提示词 @配音**：视频管理生成分镜时，含角色的分镜在原有资产标签之外，追加该角色已绑定配音的 `【@配音:名字】` 标签；该标签参与高亮与关联资产展示，但**不触发**「缺失资产」红色告警。

### 基础约定

- 素材库为**全局资源**，不随项目隔离；未选项目时也可从头部进入。
- **音乐与音效是两个独立分页**，不合并。
- 每个素材可打多个标签；标签按类型各有一套分类体系（见 3.3）。
- 配音绑定作用于**角色资产本身**，与角色的形态/状态无关；场景、道具无配音概念。
- 提示词中配音引用固定格式：`【@配音:名字】`（与资产标签 `【@资产名-状态】` 区分）。

## 2. 功能一：素材库

### 2.1 入口

- 头部右侧、生成器按钮旁新增「素材库」图标按钮，**始终可见**，不依赖是否选中项目，点击进入素材库。
- 素材库为**大级别界面**：进入后顶部标题栏整体切换为「素材库」（中间标题 + 左上角 logo），不再显示项目导航。
- 退出素材库：点击左上角 **FREELITE logo** 回到系统首页（有项目时回资产管理，无项目时回项目选择）。

### 2.2 页面与默认行为

- 顶部标题栏：左侧 logo（点击回系统首页）、中间标题「素材库」，统一由系统框架管理。
- 内容区第一行：类型分页 + 素材计数 + 右侧「搜索框 + 上传素材」按钮。
- 类型分页：配音 / 音乐 / 音效 / 图片，**没有「全部」**。
- **进入默认不选中任何类型，列表为空**，提示「请选择素材类型，加载对应素材」。
- 选中某类型后：加载该类型素材，并展开该类型专属的「标签分类 + 筛选参数」面板；切换类型时自动清空已选标签与时长筛选。
- **类型内搜索**：搜索框输入关键词，按素材**名称 / 文件名**模糊匹配当前类型素材；切换类型时清空搜索词；与标签、时长筛选叠加生效。

### 2.3 标签分类体系

- 标签按素材类型各有一套分类体系，**标签内容以产品标签文档为准**，此处只描述结构与交互。
- 展示样式：选中标签高亮（蓝色）；可同选多个标签取**交集**（素材需同时包含所有已选标签）；素材卡片上的标签可点击，直接加入/移出筛选。

**音效、图片为三级树结构**，配音、音乐为扁平「维度 → 标签」结构：

| 类型 | 结构 | 维度 / 一级分类 |
| --- | --- | --- |
| 音效 | 一级分类 → 分组 → 维度 → 标签（左侧分类导航 + 右侧分组/维度/标签） | 游戏音效 / 人类声音 / 动物声音 / 环境声音 / 日常生活 / 交通工具 / 生产办公 / 体育竞技 |
| 图片 | 一级分类 → 维度 → 标签（左侧分类导航 + 右侧维度/标签） | 通用 / 风格画风 / 构图技术 / 人物专属 / 人脸专属 / 场景专属 / 道具专属 / 动物专属 / 建筑专属 |
| 配音 | 维度 → 标签 | 配音用途 / 角色定位 / 声线气质 / 情绪 / 性别 / 年龄 / 剧情题材 / 时代背景 / 语种 / 方言口音 |
| 音乐 | 维度 → 标签 | 情绪 / 使用场景 / 使用环节 / 曲风 / 乐器 / 地域 / 节奏 / 人声 |

> 同一套标签体系在三处共用：素材库筛选、上传打标签、配音绑定弹窗筛选，保证口径一致。

### 2.4 筛选参数

位于标签面板下方：

- **长度**（仅配音/音乐/音效显示）：全部长度 / 10秒内 / 10-60秒 / 60秒以上。
- **排序**：最新上传 / 最早上传。
- **清除筛选**：一键清空标签与时长筛选（仅有筛选时出现）。
- 右侧显示已选标签摘要与结果条数。

### 2.5 素材卡片

- 预览：图片直接显示；配音/音乐/音效显示类型图标 + 音频播放器，可试听。
- 悬停右上角出现删除按钮，确认后删除。
- 信息：类型图标 + 名称、类型徽章、时长、大小、标签（最多显示 3 个，超出折叠）、原始文件名。

### 2.6 上传素材

- 弹窗字段：素材类型（四类下拉）→ 名称（选文件后默认取文件名，可修改）→ **标签分类（可多选，随类型切换）** → 选择文件（按类型限制音频/图片）。
- 选择文件后自动读取预览、时长与大小；确认后新素材出现在列表最前，立即可被筛选命中。
- 提示「演示环境建议上传小文件」，不做大小阻断。

### 2.7 空态

| 场景 | 文案 |
| --- | --- |
| 未选类型（进入默认） | 请选择素材类型，加载对应素材 |
| 有筛选且无结果 | 没有符合筛选条件的素材 |
| 无筛选且该类型无素材 | 该类型下暂无素材，点击右上角上传 |

## 3. 功能二：角色配音绑定

### 3.1 入口

- 资产管理 → 任意角色资产 → 状态详情弹窗右栏新增「配音绑定」区块。
- **仅角色显示**；场景、道具不显示。
- 区块展示当前绑定：已绑定显示配音名字，未绑定显示「未绑定」；右侧「配音绑定」按钮打开绑定弹窗。

### 3.2 绑定弹窗

- **近全屏**大弹窗，视觉与状态详情弹窗同级。
- **只包含配音类素材**，没有其他类型。
- 顶部带与素材库**完全一致**的配音标签分类与筛选参数（标签 / 长度 / 排序 / 清除），便于在大量配音中快速查找。
- 配音以卡片网格展示：麦克风图标、名称、时长、文件名、标签；**单选**，选中紫色高亮 + 对勾，再点取消。
- 打开时自动**预选当前已绑定的配音**，筛选条件重置。
- 空态：素材库无任何配音 → 「暂无配音素材，请先前往素材库上传」；筛选无结果 → 「没有符合筛选条件的配音素材」。

### 3.3 绑定 / 解绑

- **确认绑定**（未选中时禁用）：写入角色，关闭弹窗；详情区块随即显示该配音名字。
- **取消绑定**（仅已绑定时显示）：清空角色的配音绑定。
- **关闭**：不保存退出。

## 4. 功能三：提示词同步 @配音

| 环节 | 行为 |
| --- | --- |
| 分镜生成 | 分镜含角色且该角色已绑定配音时，提示词末尾自动追加 `【@配音:名字】`；未绑定保持原行为，不追加 |
| 缺失校验 | 配音标签**不参与**「缺失资产」校验，右侧缩略导航不出现红色告警 |
| 关联资产 | 提示词下方的「关联资产」区识别配音标签，以**紫色麦克风卡片**展示（名称 + 「配音」副标题），其余资产保持图片缩略图 |
| 高亮 | 配音标签与资产标签一样蓝色高亮显示 |

## 6. 边界情况与已知限制

- 角色未绑定配音：提示词不追加配音标签（保持原行为）。
- 配音素材被删除但角色仍绑定：提示词保留旧名字、不报红；**本期不做自动解绑**（已知限制）。
- 素材名允许重复，绑定关系以素材唯一标识为准。
- 标签筛选为交集语义；**未打标签的素材仅在未选任何标签时可见**。
- 素材库进入默认空列表，必须选中类型才加载（产品约定，非 Bug）。
- 上传走浏览器本地读取（演示用），正式环境需接真实存储与鉴权。

## 7. 验收清单（配合 Demo 演示）

1. 素材库：头部图标进入 → 默认空列表 → 点「配音」加载 4 条演示配音 → 选标签「女声」仅剩 1 条 → 长度「10-60秒」、排序、清除筛选均生效 → 上传一条带标签的配音后立即可被筛出、可试听 → 悬停删除。
2. 绑定：角色资产详情 → 区块显示「未绑定」→ 打开近全屏弹窗（仅配音、带标签筛选）→ 选中「磁性男声 · 旁白」→ 确认 → 区块显示名字；再次打开自动预选；「取消绑定」可清空；场景/道具资产无该入口。
3. 提示词：视频管理生成分镜 → 含已绑定角色的分镜末尾出现 `【@配音:磁性男声 · 旁白】` 蓝色高亮 → 缩略导航无红色缺失告警 → 「关联资产」区以紫色麦克风卡片展示该配音。
